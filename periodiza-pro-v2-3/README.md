# Periodiza Pro v2.0 ⚡

App PWA de periodização científica com **sincronização em nuvem** e **compatibilidade ampliada** (iOS 12+).

Novidades desta versão:
- ✅ **Sincronização automática** entre iPhone, iPad e MacBook via Supabase
- ✅ **Compatível com iPad Mini 2** (iOS 12) graças a compilação legacy
- ✅ **Login / Cadastro** por email
- ✅ **Modo offline** disponível a qualquer momento

---

## 🚀 Como publicar

### Opção A — Vercel (recomendado)

1. Crie conta em https://vercel.com
2. Em https://vercel.com/new, arraste o ZIP do projeto
3. A Vercel detecta Vite e clica em **Deploy**
4. Em ~2 minutos você recebe uma URL `https://periodiza-pro.vercel.app`

### Opção B — Netlify

1. No computador: `npm install && npm run build`
2. Acesse https://app.netlify.com/drop
3. Arraste a pasta `dist`

## 📱 Instalar nos aparelhos

**iPhone 11** e **iPad Mini 2** — mesma coisa:
1. Abrir URL no **Safari**
2. Botão compartilhar ⬆️ → **"Adicionar à Tela de Início"**
3. Nomear e confirmar

**MacBook** (Safari 17+):
1. Arquivo → **"Adicionar ao Dock..."**

**Primeira abertura** em qualquer aparelho: aparece tela de login. Faça cadastro com email/senha ou use modo local.

---

## 🔄 Como a sincronização funciona

1. **Login em todos os aparelhos** com o MESMO email/senha
2. No iPhone você cria treinos → em 2 segundos vão pra nuvem
3. Abre no iPad/MacBook → dados já estão lá
4. **Offline**: continua funcionando, sincroniza quando volta online
5. **Indicador no topo**: ☁ verde = sincronizado | ⟳ laranja = sincronizando | 📴 cinza = offline
